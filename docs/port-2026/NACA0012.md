## 1. Summary
This is the simplest of the four notebooks: gradient-based AS on 1756 samples, all plots, no surrogate. The port is mechanical and runs in about 1 s. Findings:
1. **The gradients in the data are with respect to PHYSICAL inputs**, not normalized ones as the cell-3 comment claims. Eigenvectors are unaffected, because all 18 parameters share one range. In v1, `Uniform(-0.01, 0.01)` with the raw gradients gives eigenvalues 1e-4 × the legacy values; that is the correct normalized-coordinate scaling.
2. The data has a duplicated nominal point (runs 1 and 945, identical inputs and outputs).
3. Cell 14's claim "the last 9 parameters receive higher weight than the first 9" holds for drag (Σ|w₁| 1.02 vs 2.15) but not really for lift (1.86 vs 1.94).
4. The v1 sign rule flips the drag w₂ relative to the 2016 plot. **Superseded (V1-05, [#39](https://github.com/paulcon/as-data-sets/pull/39)):** `ac.orient(by="reference")` against e₁ restores the 2016 rule, which un-mirrors drag w₂.
5. The text never says what the 18 parameters are (upper/lower surface split, bump locations), nor gives the flow conditions. The book doesn't either: "transonic, compressible", SU2 adjoint, bump heights, nominal 0, range ±0.01 (p. 82). The README "18-parameter" is correct.
6. **Book vs. data:** book §5.3.1 uses Alg. 3.3 with k = 7, α = 6, so **M = 122** gradient samples and 1000 bootstrap replicates. The file has 1756 rows. Eigenvalues of the **first 122 rows** (drag 6.47, 1.45, 0.58, 0.42, 0.106, 0.045, 0.017; lift 877, 47, 28, 19, 6.6, 4.3, 3.4) match book Fig. 5.11 read off the plot, so the book used rows 1–122, with the same unscaled physical gradients. The book concludes drag is "one- or four-dimensional" (p. 83; λ₁/λ₂ ≈ λ₄/λ₅ ≈ 4 at M = 122). On all 1756 rows λ₄/λ₅ = 2.7, and the notebook's "2- or higher" is a different, data-driven reading.

## 4. Code review
- pandas `from_csv`/`as_matrix` were removed in pandas 1.0. `df.keys()` is used for labels.
- `xl = -0.01*np.ones((1, m))` (2-D bounds) is legacy-specific.
- `ss.partition(2)` mutates the object in a loop. v1 returns new results (`ac.with_dimension`).
- The bootstraps (`nboot=200`) are unseeded. Use `rng=`.
- No wasted computation, no hard-coded paths. Runtime is trivial.

## 5. Data management review
- One 2.35 MB CSV, well under the 50 MB warning. The `%.16e` precision is more than needed but harmless.
- The header is good (Run, x01…, Lift, Drag, dlift.., ddrag..). Units are implicit (coefficients, dimensionless).
- Inputs are stored **physical**. Normalization is not stored; the bounds ±0.01 live only in the notebook.
- Gradients are **physical** (see §3). The column names do not say so. Document it in the notebook.
- Redundancy: run 945 duplicates run 1 (nominal design). This suggests the file concatenates two batches (runs 1–944 and 945–1756), each starting at the nominal point. Harmless for MC averaging (1/1756 extra weight on the nominal point). Mention it or drop it with `np.unique`; author decision.
- The book's Fig. 5.11 used the first 122 rows (see §1 item 6).
- Provenance/license: none in the directory. The data came from SU2 runs by T. Lukaczyk (commit 51a93cd, 2014).
- **Tested pandas-free loader:**
```python
import numpy as np
```

## 10. Prototype results
Script: `prototypes/g3/airfoils.py NACA0012/NACA0012.txt 18 0.01`
- v1 `active_subspace(grads=G, space=Uniform(±0.01), nboot=200)`: 0.4 s per QoI, no warnings.
- Ratio of v1 to legacy eigenvalues = 1.0000e-4 exactly. The legacy plot (cell 9 PNG) shows λ₁ ≈ 855, matching the legacy computation.
- Eigenvectors: lift w₁, w₂ and drag w₁ agree with legacy to 2e-15. Drag w₂ agrees after a sign flip. **Superseded (V1-05, [#39](https://github.com/paulcon/as-data-sets/pull/39)):** after `ac.orient` drag w₂ agrees without a flip.
- Gaps λ₁/λ₂: lift 15.9, drag 5.2. Poly-2 LOO R²: lift 0.934 (n=1), 0.965 (n=2); drag 0.870 (n=1), 0.928 (n=2).
- Physical-gradient check: lstsq of f on normalized X, divided by the mean gradient, gives 0.01002 (lift) and 0.01019 (drag).
- Book check (inline): eig(GᵀG/M) on rows 1–122: drag 6.47, 1.45, 0.583, 0.416, 0.106, 0.045, 0.017; lift 877, 47.4, 27.7, 18.9, 6.58, 4.26, 3.41. These match book Fig. 5.11 (p. 83, read off the log plot: drag ≈ 6, 1.4, 0.55, 0.4, 0.1, 0.045, 0.017; lift ≈ 8e2, 45, 25, 20, 6, 4, 3.5). The book's eigenvalues are therefore also in unscaled physical-gradient units, even though p. 82 describes the normalized hypercube.
